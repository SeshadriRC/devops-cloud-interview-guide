Docker is a containerization platform used to package an application along with all its dependencies into a container.

Benefits:

* Same application runs everywhere.
* Faster deployment.
* Lightweight compared to VMs.
* Easy scaling.
* Consistent environments.

Workflow:

```
Dockerfile
      ↓
docker build
      ↓
Docker Image
      ↓
docker run
      ↓
Container
```
