**Role Description**

The DevOps Engineer acts as a bridge between software development, infrastructure, and operations, with a strong focus on building secure, scalable, and automated delivery pipelines. This role involves designing and maintaining CI/CD pipelines, integrating Azure DevOps, implementing application and infrastructure deployment automation, and ensuring quality, security, and governance across the software delivery lifecycle.

The ideal candidate will have hands-on experience in pipeline automation, cloud and infrastructure provisioning, security scanning, code quality integration, and scripting across enterprise environments.

Key Responsibilities
   
**CI/CD and Pipeline Automation**

- Design, develop, and maintain end-to-end CI/CD pipelines using Azure DevOps. Build and manage application and infrastructure pipelines to automate build, test, deployment, and release processes.

- Implement reusable pipeline templates and standardize delivery workflows across multiple teams and applications. Integrate pipelines with source control, artifact repositories, testing tools, and deployment environments.

**DevOps and Security Integration**

- Integrate JFrog Xray for artifact scanning and vulnerability detection. Implement Advanced Security controls and security checkpoints within the CI/CD process.

- Integrate SonarQube for static code analysis, code quality checks, and quality gates. Ensure security, compliance, and governance are embedded into build and deployment automation.

- Implement secure handling of secrets, certificates, and credentials using enterprise-approved tools and practices.

**Governance and Template Integration**

Develop and maintain governed pipeline templates for standardized and compliant deployments. Support governance template integration for application and infrastructure delivery.

Ensure pipeline designs align with enterprise architecture, security policies, and release governance standards. Enforce approval workflows, branching strategies, and deployment controls as required.

**Infrastructure and Automation**

Support infrastructure automation and provisioning using IaC and configuration management tools. Collaborate with cloud and infrastructure teams to automate environment creation and deployment readiness.

Maintain scripts and automation for repeatable operational tasks and platform management. Support deployment automation across application, middleware, and infrastructure layers.

**Scripting and Configuration Management**

Develop automation scripts using Bash, PowerShell, and Python.

Use configuration management tools such as Ansible, Puppet, and Chef for application and infrastructure configuration. Automate repetitive operational tasks, environment setup, validation, and remediation activities.

**Monitoring, Troubleshooting, and Support**

Troubleshoot build failures, deployment issues, pipeline errors, and integration problems. Collaborate with development, security, and infrastructure teams to resolve delivery bottlenecks.

Ensure high availability, stability, and reliability of deployment processes and environments. Support continuous improvement of DevOps practices, automation, and tooling.


**Skills and Experience:**

Experience: 8+ years of hands-on experience in DevOps, build/release engineering, or platform automation roles.

Strong experience with Azure DevOps for CI/CD design and implementation.

Hands-on experience with CI/CD pipeline creation, management, and optimization.

Experience integrating JFrog Xray, SonarQube, and other security/code quality tools into pipelines.

Experience with advanced security scanning and enterprise DevSecOps practices.

Strong understanding of governed template integration and standardized deployment frameworks.

Experience in building application and infrastructure pipelines.

Proficiency in Bash, PowerShell, and Python scripting.

Hands-on experience with Ansible, Puppet, and Chef.

Good understanding of version control systems, branching strategies, and release processes.

Strong troubleshooting skills with the ability to resolve pipeline and automation issues quickly.
